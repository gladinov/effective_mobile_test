## Swagger

Swagger UI доступен по адресу:
`/swagger/index.html`

Если сервис запущен локально на `8080`, страница будет доступна здесь:
`http://localhost:8080/swagger/index.html`

Для регенерации swagger-документации:
```bash
make swagger
```
